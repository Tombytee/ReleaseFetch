    Three steps from link to install

    No digging through the Assets list on a small screen.

    1. Paste a repository URLAny public GitHub repository that publishes releases.
    2. Check the highlighted fileReleaseFetch reads your device’s architecture and marks the compatible assets.
    3. Download and installFiles download inside the app, ready to open.

    What’s inside

    Repository lookup
    Fetches every release of a public repository from the GitHub Releases API.
    Architecture matching
    Recognises arm64-v8a, armeabi-v7a and x86_64 builds and highlights yours.
    Downloads in the app
    Pick an asset and download it without leaving ReleaseFetch.
    Update checker
    Tells you when a newer version of ReleaseFetch is out.
    Release browser
    Move between versions and see each one’s assets in a clear list.
    Material 3 design
    An adaptive interface built for Android, in light and dark.
